HTTP/1.1 (1999)

Persistent Keep-Alive

Single FIFO queue. Responses must arrive in exact request order. Stalled requests cause Application HOL Blocking.

HTTP/2 (2015)

Binary Framing & Multiplexing

Interleaved frames on 1 TCP socket. Eliminates app HOL blocking, but introduces TCP-Layer HOL Blocking on packet loss.

HTTP/3 (2022)

QUIC over UDP

Independent streams on UDP datagrams. Lost packet on Stream A never delays Streams B & C. True 0-RTT resilience.

HTTP/1.1: The Application Head-of-Line Bottleneck

In HTTP/1.1, responses cannot be tagged with stream IDs. The server is strictly bound to send data back in the exact order requested. Because Stream A (report.pdf) takes 900ms SQL execution time, Stream B (style.css) and Stream C (app.js) finish in server memory in 30-40ms but are completely trapped behind Stream A!
